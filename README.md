**Understand Earth and space images with AI.**

SpaceSnap AI analyzes NASA and other Earth-observation images using
Google Gemini. It produces beginner-friendly explanations, identifies
visible features, estimates their locations, and creates annotated images.

## Features

- Upload PNG, JPG, JPEG, or WEBP images
- AI-generated image descriptions
- Identification of visible features
- Approximate bounding boxes and colored labels
- Download annotated images
- Beginner-friendly explanations and limitations

## Technology Stack

- Python
- Streamlit
- Google Gemini API
- Pillow
- NASA Images API for sample-image discovery

## Setup

1. Install Python 3.10 or later.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Set your Gemini API key as an environment variable.

   Linux/macOS:

   ```bash
   export GEMINI_API_KEY="YOUR_API_KEY"
   ```

   Windows PowerShell:

   ```powershell
   $env:GEMINI_API_KEY="YOUR_API_KEY"
   ```

4. Start the app:

   ```bash
   streamlit run app.py
   ```

5. Open the local URL displayed by Streamlit.

## Limitations

Feature locations are estimates generated by a multimodal AI model.
They are not scientifically verified detections. The model can produce
inaccurate bounding boxes, misinterpret map overlays, or describe
features incorrectly. Results should not be used as operational fire
alerts or for emergency decisions.

## Security

Never commit API keys, credentials, or `.env` files to GitHub.
